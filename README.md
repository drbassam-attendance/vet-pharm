# فيت فارم — إدارة صيدلية بيطرية

تطبيق ويب عربي (RTL) لإدارة صيدلية بيطرية: مخزون بالأصناف والكراتين والمل، بيع مع كشف، مشتريات وموردين، عملاء وديون، تقارير وتصدير.

- الموقع: https://drbassam-attendance.github.io/vet-pharm/
- الواجهة: HTML/CSS/JS بدون أي مكتبات خارجية.
- البيانات: Supabase (مجاني) مع Row Level Security — كل صيدلية لا ترى بيانات غيرها.
- ملف قاعدة البيانات: schema.sql ثم schema2.sql ثم schema3.sql (تُشغَّل مرة واحدة في SQL Editor).
